# 嘴替鸭 · 拆招 / 语录 / 出招 三页改版规划

> 目标：在不改业务逻辑的提前下，让三个核心页面更符合人的阅读习惯、降低阅读压力、提升停留与转化。
> 手段：图标先行 + 长文折叠 + 小鸭手绘 IP 当情感载体 + emoji 轻标记 + 留白与分隔。
> 约束：纯前端视觉重构，不改动 AI 输出格式（`engine.ts` / `analysis.ts` 不动），兼容旧数据。

---

## 一、总原则（阅读习惯）

| 原则 | 做法 | 反例（现状） |
|---|---|---|
| 图标先于文字被识别 | 每个区块/分类配图标或 emoji | 分类是一排纯文字 chip |
| 先给结论，长文可折叠 | 回话顶部加「口诀」，分析默认收起 | situation / reason 整段摊开 |
| 留白与分隔，别一大块 | 卡片内分区用色条/分隔线/留白 | 一大段灰字堆在一起 |
| 情感化降低压迫感 | 小鸭 IP 在思考/空态/解锁时出场 | 只有 logo 角标，无情绪 |
| 行动按钮清晰 | 复制 / 拿去练手 / 朗读 一眼可见 | 功能靠文字链接 |

统一视觉语言（与小桃公众号封面一致）：底色 `#FFFDF8`、马卡龙配色、珊瑚红 `#E8655A` 作唯一强调色、圆角卡片、0.5px 细描边。

## 二、手绘 IP 与图标策略

### 1. 小鸭 IP 升级（核心素材）
现状只有 `src/assets/logo.png`（扁平小鸭）。建议新增一套「鸭鸭表情包」手绘 PNG（200×200，透明底，统一描边 + 柔色）：
- `duck-think.png` 托腮思考 → 用在拆招「分析中」
- `duck-shrug.png` 摊手 → 用在空态 / 无结果
- `duck-go.png` 出击姿态 → 用在出招 hero
- `duck-pocket.png` 翻口袋 → 用在语录空态（引导加语录）
- `duck-nod.png` 点头 → 用在「已为你想好 N 套」
- `duck-lock.png` 捂锁 → 用在登录解锁卡

风格：与公众号小桃 Q 版水彩一致（可复用其水彩笔刷）。小程序品牌是小鸭，建议保持小鸭 IP 不混用真人 IP，避免品牌混乱；若想用真人 IP 需评估合规。

### 2. 图标三档用法
- **线性图标**（复用现有 tabbar svg 风格）：功能按钮、步骤、筛选。
- **emoji 轻标记**：场景类型 / 情绪 / 分类（零资源、即时可用）。如 职场💼 暧昧💗 家庭🏠 朋友🍻 试探🔍 施压⚠️。
- **手绘 IP**：只在「思考 / 空态 / 解锁 / hero」等关键情绪节点出场，不当装饰滥用。

## 三、拆招页（defend，也是首页）改版

现状：欢迎区（logo+三步数字流程）→ InputPanel → 结果区（思考动画 / 空态 / IntentCard + 我的语录命中 + 多条 ResponseCard）→ 页脚。

### 改版点
1. **欢迎区**
   - logo → `duck-nod` 手绘小鸭，文案更口语：「接不上话？把原话丢给鸭鸭」。
   - 三步流程：数字 `1 2 3` → 图标+emoji：`📋 粘贴原话 → 🔍 识别意图 → 📋 复制回话`，用箭头连线更轻。
2. **思考态**：`duck-think` 托腮 + 三点动态省略号，文案「鸭鸭正在拆对方的话…」（比纯转圈友好）。
3. **空态**：`duck-shrug` 摊手 + 「把接不上话的原话丢给鸭鸭吧」，加一个输入框快捷入口暗示。
4. **结果区**
   - 顶部：「为小主想了 N 套回话 🦆」小鸭点头 + 计数。
   - **IntentCard（重写）**：
     - 意图 `intent[]` → 带 emoji 图标 chips：`🔍 试探` `💬 邀约` `⚠️ 施压`。
     - `situation` 长段 → 「对方在想什么 💭」手绘气泡 + 2~3 个短要点，详情默认折叠（点「详情 ▾」展开）。
   - **我的语录命中**：✨ 卡片加「鸭鸭觉得这条也合适」推荐语 + 小鸭贴纸角标。
   - **ResponseCard（重写）**：每条 = 口诀锚点（`reasonShort`，如「先接后拒，留台阶」）+ 回话正文（始终展开）+ 为什么有效（折叠）+ 操作行（🔊 朗读 / 📋 复制 / ➕ 收进语录）。
5. **页脚 tip**：从纯文字改为「鸭鸭气泡」样式，小鸭在旁：「鸭鸭只是帮你组织语言，开口前结合当下语境哦～」。

## 四、语录页（quotes）改版

现状：hero（logo+文案）→ Tab（全部/我的）→ 搜索框+刷新 → 分类 chips → 计数 → QuoteCard 列表 → ➕ 添加 → 登录解锁卡。

### 改版点
1. **hero**：`duck-pocket` 手绘（举着话术本）→ 文案「看到合适的，拿去练手」更短平快。
2. **Tab**：全部语录 📚 / 我的语录 ✨（加 emoji + 激活态加小鸭下划线）。
3. **搜索**：放大镜 🔍 + 占位「搜搜看有没有你的嘴替」更口语；清除 ✕ 保留。
4. **分类 chips**：每类配 emoji（职场💼 暧昧💗 家庭🏠 朋友🍻 职场汇报📊 …）。
5. **QuoteCard（重写）**：
   - 顶部：分类色条 + 来源徽章（固定库 / 🔥 每日热话 / ✨ 我的）。
   - 正文：话术气泡样式（鸭鸭开口气泡），不是普通文本框。
   - 右上角：emoji 心情标记（如 😎 硬气 / 🤗 软萌 / 🧊 冷静）。
   - 操作行：🚀 拿去练手（主按钮，醒目珊瑚红）/ ✏️ 编辑 / 🗑 删除（图标，仅我的语录）。
6. **空态**：`duck-pocket` 翻口袋 + 「还没有语录，点右下角把用过的好话术记下来」。
7. **添加按钮**：光秃秃 ➕ → 小鸭圆浮标 💬＋（更可爱、引导更强）。

## 五、出招页（attack）改版

现状：hero（logo+文案）→ 分类 chips → 计数 → SceneCard 列表（开场话术 + 谈话闭环）→ 登录解锁卡。

### 改版点
1. **hero**：`duck-go` 出击小鸭 → 文案「不用等别人先开口」。
2. **分类 chips**：加 emoji（同语录分类体系）。
3. **SceneCard（重写）**：
   - 标题行：场景 emoji 图标 + 场景名 + 「适用情境」手绘标签。
   - **开场话术**：鸭鸭开口气泡样式 + 📋 复制，一眼可见。
   - **谈话闭环**：从纯文字段 → 步骤流（1️⃣ 破冰 → 2️⃣ 抛话题 → 3️⃣ 收尾），用横向步骤卡或手绘箭头串联，扫一眼懂流程。
4. **登录解锁卡**：`duck-lock` 捂锁手绘 + 软文案「还有 N 个场景，登录全拿走」。

## 六、落地清单（按性价比排序）

| 优先级 | 任务 | 文件 | 工作量 | 依赖 |
|---|---|---|---|---|
| P0 | 拆招 IntentCard 图文化（chips+要点+折叠） | IntentCard | 低 | 无 |
| P0 | 拆招 ResponseCard 口诀+折叠+朗读占位 | ResponseCard | 低 | 无 |
| P0 | 语录/出招分类 chips 加 emoji | quotes/attack scss | 极低 | 无 |
| P1 | 鸭鸭表情包手绘素材（6 张 PNG） | assets/ | 中 | 需设计/AI 出图 |
| P1 | 三页空态/思考态换手绘 IP | 各页 + EmptyState | 低 | P1 素材 |
| P1 | QuoteCard/SceneCard 气泡样式 + 来源徽章 + 心情标记 | QuoteCard/SceneCard | 中 | 无 |
| P2 | 朗读 TTS 真接入（微信同声传译插件） | ResponseCard + MP 后台 | 中 | 需后台加插件 |
| P2 | hero/页脚鸭鸭气泡化 | 各页 scss | 低 | P1 素材 |

> 说明：P0 纯前端、零素材，今天可做且立刻见效；P1 的手绘素材是体验跃升的关键，但需要出图（你可提供小桃 IP 同款水彩，或我协助用 ImageGen 生成小鸭系列）；P2 涉及后端/插件，排最后。

## 八、与提审的关系

本规划是纯视觉/体验优化，**不影响功能完整性，不阻断提审**。建议顺序：先按现状提审（功能已完整）→ 审核通过后再渐进式做 P0→P1→P2，降低上线风险。若想提审前就做，P0 部分零风险可直接并入。
