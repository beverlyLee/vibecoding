## 一、IP 原型（以现有 `src/assets/logo.png` 为准）

实图特征，**所有新图标必须由它变换而来，不要另起画风**：

| 部件 | 特征 |
|---|---|
| 主体 | 亮黄色圆脸小鸭，头身一体、圆润无棱角 |
| 描边 | 粗黑/深棕描边，平涂无渐变、无阴影、无高光 |
| 眼睛 | **黑圆框眼镜** + 眯眼弯弯笑（最核心的识别锚点） |
| 服装 | 蓝色衬衫 + 棕色背带裤 |
| 道具 | **手握黑色麦克风**（"嘴替"设定的灵魂，尽量保留或变通携带） |
| 姿态 | 左手举起打招呼，身体微侧 |
| 腮红 | 两坨淡橙腮红 |
| 背景 | 白色 / 透明，无文字 |

**变换三维度**（只变这三样，其余保持一致，一套图才像一家人）：
1. **表情**：眯眼笑 / 睁眼坚定 / 挑眉坏笑 / 皱眉 / 鼓腮 / 眨眼 / 摊手无奈
2. **手势**：举手 / 摊手 / 平举「停」/ 指向 / 握手 / 捧心 / 托腮 / 竖拇指 / 翻口袋
3. **道具**：麦克风 / 放大镜 / 拳套 / 公文包 / 砖墙 / 盾牌 / 靶心 / 话气泡 / 星星 / 小锁

> 建议色值（以 logo 原图取色为准）：鸭黄 `#FFD23F`、描边 `#2B2B2B`、衬衫蓝 `#4A9FE0`、背带棕 `#8B5A2B`、腮红 `#FFB07C`、麦克风深灰 `#333333`。

## 二、统一规格

| 项 | 要求 |
|---|---|
| 尺寸 | **200 × 200 px**（按 @2x 出 400×400 更稳），主体居中占约 80% |
| 格式 | PNG **透明底**，不要自带圆底/描边框——底色由代码里的分类浅色圆底承托，一套图才能适配 8 种分类色 |
| 风格 | 平涂、黑粗描边（约 6–8px @200）、**无文字、无数字、无渐变、无投影** |
| 必留锚点 | 圆框眼镜 + 蓝衬衫（背带可省略）+ 尽量带麦克风或其变体；至少保留眼镜 |
| 命名 | `ip_cat_*.png` / `ip_style_*.png` / `ip_intent_*.png` / `ip_state_*.png` / `ip_tab_*.png` |
| 存放 | `src/assets/ip/`（出图后新建，现无此目录） |
