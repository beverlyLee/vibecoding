### 详细介绍（Markdown，整段复制进“详细介绍”框）

```markdown
# 治愈系图片生成器

> 用 Vibe Coding 把"治愈感"做成一套可复现的设计系统——上传一张照片，几秒得到一组自带留白与呼吸感的治愈系图文卡片。

## 这是什么

一个**纯前端的治愈系图文卡片生成器**。你上传照片、写下一句话，工具帮你套用经过打磨的治愈系配色、字体、版式与留白规则，一键导出可直接发朋友圈 / 小红书的成图。

它有两种出图模式：
- **模板模式（零门槛）**：完全本地运行，不需要任何 API Key，离线也能用。
- **AI 生图模式（可选）**：接入火山方舟 / OpenAI 兼容接口，用 AI 把一句话扩写成画面、并保持系列"主角一致性"。Key 存在你浏览器本地，成本自担。

## 为什么做

治愈系图文是高频需求，但"对味"很难：配色一踩雷就变土味，留白一少就显拥挤。我把"什么是治愈感"拆成可复用的规则——晚樱粉 / 薄荷绿 / 天青蓝三套色板、与情绪联动的 10 款字体、固定比例的呼吸留白——让普通人也能稳定产出"看着就舒服"的图。

## 核心功能

- **5 种版式**：单图金句、九宫格日记、三图故事、拼贴海报、长图手账
- **5 种比例**：1:1 / 4:5 / 3:4 / 16:9 / 9:16，覆盖各平台
- **3 套色板 + 自动模式**：自动模式会按照片主色 / 文案情绪智能选色（亮粉照片稳定命中晚樱粉）
- **10 款字体 × 情绪联动**：温柔 / 元气 / 安静 / 复古，字体随情绪切换
- **逐卡编辑与草稿**：每张卡片可单独改字、换图、调色，支持本地草稿续编
- **一键导出 PNG**：适配社媒发布尺寸

## 技术亮点（Vibe Coding 视角）

- **React + Vite 纯前端 SPA**，无后端、无数据库，部署成本为零
- 三层单向数据流架构，状态可预测、易扩展
- **CORS 代理**：火山方舟生图需服务端转发，我用零依赖 `server.js` 在单一端口内同时做静态托管与 `/proxy-ark` 反代，所以线上 AI 生图也是正常的

## 适用场景

- 朋友圈 / 小红书 / 公众号的日更配图
- 手账、日记、读书笔记的视觉化
- 活动 / 店铺的治愈风海报快速出图
- 给不会设计的朋友做一张"刚刚好"的图

## 使用边界

- AI 生图需自备 Key，成本自担；不填 Key 也能本地模板出图
- 生图依赖供应商服务，断网或额度耗尽时自动回退到模板模式
- Key 仅存本地浏览器，不上传任何服务器
- 不生成违规 / 侵权内容
