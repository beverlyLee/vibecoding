# 治愈系图片生成器 · 作品介绍

> 一份面向活动发布与用户使用说明的结构化文档。涵盖作品背景、定位、功能详解、适用边界与差异化特色。

---

## 一、背景

在小红书、公众号、朋友圈等平台上，「治愈系图文卡片」是高频内容形态——一张温柔的照片、几句安抚人心的文字、统一的奶油色调，能轻易营造出让人松弛下来的氛围。但随手拼一张图并不轻松：配色要统一、字号要舒服、文字要会"说话"，多张卡片还要保持风格一致。

市面上的修图/排版工具要么偏「专业后期」（门槛高），要么偏「模板套壳」（风格趋同、缺乏情绪），要么把 AI 当噱头（出图随机、文字和画面各说各话）。

**治愈系图片生成器**的出发点很简单：把"治愈感"做成一套**可被工程复现的设计系统**——固定的低饱和色板、留白呼吸的版式、会承接情绪的文案风格，再叠加可选的 AI 能力（按文案重绘场景、自动写金句），让人不用懂设计也能稳定产出"对味"的卡片。

---

## 二、作品简介

**治愈系图片生成器**是一款纯前端、打开即用的图文卡片制作工具。上传照片 + 写一句心情（或让 AI 代写），一键生成多张风格统一的治愈系卡片，支持 5 种版式、多种比例、智能配色与字体联动，并可导出单张图片或整套 ZIP。

- **形态**：浏览器 Web 应用（React + Vite，无后端、无账号、无需安装）
- **运行**：线上链接即点即用，也支持本地双击运行
- **核心定位**：让"不会设计的人"也能稳定产出"有情绪、不违和"的治愈系图文卡片
- **线上地址**：https://c269b7d286ff4040839123675a571b09.app.workbuddy.link

## 三、详细介绍（功能模块）

### 3.1 两种创作模式
| 模式 | 输入 | 产出 |
|---|---|---|
| **默认模式** | 1 张照片 + 一段文案 | 文案自动切分为 N 段 → N 张卡片（每段一卡） |
| **逐图模式** | N 张照片 | N 张卡片（每张照片配对应文案/情绪） |

### 3.2 版式系统（5 种）
- **居中留白**：照片居中、四周留白，文字居中
- **左文右图**：文字在左、照片在右
- **上下分栏**：照片在上、文字在下
- **圆形裁切**：照片圆形裁切，温柔感强
- **图文叠加**：照片铺满整卡，文字叠加于图上（上 / 中 / 下三档位置）

### 3.3 输出比例（5 种）
默认 2:3 竖版（1080×1620），适配小红书/朋友圈；另支持 3:4、4:5、1:1 方形、9:16 长图，覆盖多平台发布需求。

### 3.4 调色板（背景）
- 3 套预设治愈色板：**奶油暖阳**（暖橘）、**晚樱粉**（柔粉）、**雾霭蓝**（静蓝）
- **自动模式**：根据照片主色调与明暗，智能匹配最贴合情绪的色板（如亮粉照片稳定命中晚樱粉）

### 3.5 字体
- 内置可下载：**思源黑体**、**站酷快乐体**（圆润可爱）
- 内置可选（联网加载失败自动回退系统字体）：**霞鹜文楷**
- 系统字体族（无需下载，跨端回退）：宋体 / 楷体 / 仿宋 / 黑体 / 圆体 / 行楷
- **情绪联动**：文案含"喜欢/温柔/晚安"等 → 自动偏晚樱粉 + 文楷；含"阳光/开心" → 奶油暖阳 + 快乐体；含"安静/独处" → 雾霭蓝 + 黑体

### 3.6 逐卡编辑与草稿
- 每张卡片可单独**改文案**、可**上传替换该卡图片**（仅影响本卡，其余不变）
- 支持**草稿保存**：未完成的作品存入本地草稿，随时续作

### 3.7 导出
- 单张导出 **JPG / PNG**
- 整套导出 **ZIP 打包**（零依赖自研压缩，中文文件名不乱码）

### 3.8 可选 AI 能力（需自备 Key）
开启后多两项能力，均**用你自己的 API Key、走你自己的额度**：
1. **AI 自动写治愈文案**：按"意象承载情绪、允许与接纳、先抑后扬、对仗排比、金句收尾"的风格基因生成文案
2. **卡片级 AI 生图/换图**：把"该卡文字 + 当前图"发给大模型重绘——保持画面主角一致（人物/宠物特征不变），仅重绘背景与氛围以呼应文案，做到图文一体

支持的供应商：
| 供应商 | 生图模型 | 说明 |
|---|---|---|
| 火山方舟 | doubao-seedream 系列 | 线上经内置反代绕过跨域限制 |
| OpenAI | gpt-image-1 | 走 `/images/edits` 多模态图生图 |
| 自定义网关 | 任意 OpenAI 兼容 | 填 baseUrl 即可适配中转 |
| 腾讯混元 | — | 仅文本模型，本工具暂不支持其生图 |

## 四、适用范围

### 适合谁 / 什么场景
- **自媒体运营者**：小红书、公众号、朋友圈配图，批量产出风格统一的治愈系九宫格/长图
- **个人记录**：旅行、日常、心情卡片，把碎片照片变成可分享的情绪日记
- **内容创作者**：做"晚安语录""周末温柔""自我关怀"等主题卡片
- **礼品与问候**：生日、晚安、想你、鼓励类电子贺卡
- **不追求专业后期、但要求"看着舒服、情绪对"的用户**

### 不适用的边界
- ❌ 需要精确商业排版（网格对齐、出血、印刷 CMYK）
- ❌ 真实摄影精修（磨皮、局部调色、物体擦除）
- ❌ 服务器端的多人协作/集中管理/模板市场
- ❌ 依赖第三方大模型生图时，对出图速度/稳定性有强要求的生产场景（受模型侧限速影响）

## 五、使用方法

### 基础出图（无需 AI，完全本地）
1. 打开链接，进入首页
2. **上传照片**：拖入或选择 1–9 张（JPEG / PNG / WebP，单张 ≤ 10MB）
3. **写文案**：在文案框输入一句心情；不写则由既有文案/情绪驱动
4. **选风格**：在控制栏挑版式、调色板（建议选"自动"）、字体
5. 点**生成**，预览区即时出现多张卡片
6. **逐卡微调**：点卡片进入编辑，改文字或替换该卡图片
7. **导出**：单张下载 JPG/PNG，或点 ZIP 打包整套

### 开启 AI（可选）
1. 点右上角**设置**打开 AI 设置抽屉
2. 开启 AI，选择供应商（如火山方舟），填入**你自己的 API Key 与模型名**
3. 保存后：文案框可让 AI 代写；卡片操作栏出现「AI 图」按钮
4. 点「AI 图」即按该卡文字 + 当前图重绘新图（仅替换本卡）

> 配置存于浏览器本地，刷新不丢；换设备需重新填写。

## 六、使用边界与隐私说明

- **照片处理**：未开启 AI 时，照片**仅在你的浏览器本地处理**，不上传任何服务器；开启 AI 生图后，照片会按你选择的供应商发往对应大模型。
- **密钥与成本**：AI Key 存于本地浏览器，各人用各人额度；应用不为任何访客承担 API 费用。
- **失败兜底**：AI 调用失败或超时，自动回退到固定预设并提示，**不中断出图**。
- **网络依赖**：基础功能仅需首次加载字体资源；AI 功能需网络可达对应大模型服务。
- **内容边界**：生成内容由使用者负责，请遵守所选大模型平台的内容政策与版权规范。

## 八、产品特色（差异化）

- **情绪引擎**：文案情感词 ↔ 配色/字体联动（晚樱粉+文楷、奶油暖阳+快乐体、雾霭蓝+黑体），让视觉自动贴合文字情绪。
- **照片主色自动配背景**：基于图像主色与亮度分析智能选色板（亮粉权重优先，保证粉调照片稳定命中晚樱粉）。
- **图文叠加版式**：图铺满 + 文字上/中/下三档，文字带柔和阴影保证可读性，治愈氛围拉满。
- **主角一致性 AI 生图**：图生图时锁定人物/宠物特征，仅重绘场景呼应文案，做到"图文一体"而非"文图各说各话"。
- **治愈系文案基因**：内置"意象承载情绪、允许与接纳、先抑后扬、金句收尾"的写作规范，产出有林清玄/汪曾祺式的通透淡然。
- **留白与呼吸感**：低饱和奶油色系、柔和漫射光、轻微胶片颗粒，大面积留白，天然适合做文字卡片背景。

## 九、技术架构（简述）

三层单向数据流，引擎与框架解耦：

```
UI 层 (React 组件) → dispatch → Store (useReducer + Context)
                                  ↓ 状态
引擎层 (纯 TypeScript，零 React 依赖)：色板匹配 / 图像分析 / 文案切分 / Canvas 合成 / ZIP 编码 / AI 桥
                                  ↓ Canvas
合成与导出 (HTMLCanvasElement → 下载 / ZIP)
```

- 无后端、无数据库、无账号；状态在浏览器内闭环
- 引擎层纯函数化、可单测（splitEngine / colorEngine / zip 均有单测）
- 构建产物为静态资源，可部署于任意静态托管或带反代的服务（已内置 `server.js` 与 Vercel/Netlify 配置）

## 十一、常见问题（FAQ）

**Q：必须填 API Key 才能用吗？**
A：不需要。不填 Key 也能上传照片、写文案、生成并导出卡片，全部本地完成。Key 仅在你想用 AI 写文案/AI 生图时才需要，且用你自己的额度。

**Q：我的照片会被上传吗？**
A：未开启 AI 时不会，照片只在本地浏览器处理。开启 AI 生图后，该张照片会发给所选大模型用于重绘。

**Q：生成的图能商用吗？**
A：基础排版产物归你；若使用 AI 生图，请遵循对应大模型平台的版权与内容政策。

**Q：为什么有的字体显示成了系统默认字体？**
A：霞鹜文楷为联网加载，网络不可达时会回退到系统衬线字体；其余字体均有本地回退族，不影响阅读。

**Q：最多能传几张、导出多大？**
A：最多 9 张；默认输出 1080×1620（2:3），可切换 3:4 / 4:5 / 1:1 / 9:16。
